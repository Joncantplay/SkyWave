# Changelog

## 1.0.0

First complete version.

**Streams and sound**
- Internet radio in vehicles and on placed radios: MP3, AAC, HE-AAC; Icecast/Shoutcast,
  `.m3u`/`.pls`, HLS (MPEG-TS, packed audio, fragmented MP4, AES-128). Automatic reconnect,
  fallback URLs.
- 3D audio with distance, direction, air absorption and muffling by closed vehicles.
- In-vehicle sound from the front of the cabin (cars and boats, all vehicles, or stereo).
- Master volume, volume boost up to 4x with a soft limiter, mute per radio or all radios, mute in
  background.

**Multiplayer**
- Server-side state with join-in-progress support and permission checks.

**Radio window**
- Station list with search, sorting by name or genre, copyright-free filter and favourites.
- Station logos, album covers (MusicBrainz / Cover Art Archive), track title with copy on click,
  connection status, last ten tracks.
- On/off, random station, volume, personal mute, custom URLs, Streamer Mode button.
- Movable and resizable window, size setting for text and controls.
- Station manager for personal and server station lists.

**Stations**
- 25 default stations, among them four copyright-free ones.
- Stations from mod config, CBA settings (server-wide and personal) and scripts, with conditions.

**Server options**
- Custom stream URLs, pictures for custom streams, copyright-free only, radio only with the engine
  running, operation from outside, driver/commander only, audible range.

**Zeus, Eden, ACE, keys**
- Placeable radio; Eden attributes for the starting station (list) and volume.
- Zeus modules: open radio, turn object into radio, remove radio, Zeus control only.
- ACE interaction menu entries.
- Keys for opening the radio, volume, next/previous station, Streamer Mode and mute all.
- English and German.
